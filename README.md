# 🏨 Hotel Booking Analysis Using Python

### Exploratory Data Analysis | Python | Data Visualization

---

## 📌 Project Overview

This project focuses on analyzing hotel booking data to identify booking patterns, guest preferences, cancellation trends and revenue-related insights.

The analysis explores data from both City Hotels and Resort Hotels to understand customer behaviour and uncover meaningful business insights that can support better decision-making.

## 🎯 Project Objectives

- Analyze hotel booking patterns and trends.
- Understand customer preferences and booking behaviour.
- Identify factors associated with booking cancellations.
- Compare City Hotel and Resort Hotel performance.
- Explore revenue trends and Average Daily Rate (ADR).
- Provide business recommendations based on the analysis.

## 🗂️ Dataset Information

The dataset contains hotel booking records for City Hotels and Resort Hotels.

It includes information related to:

- Booking dates and lead time
- Guest details and customer types
- Hotel and room types
- Booking cancellations
- Distribution channels and market segments
- Revenue and Average Daily Rate (ADR)
- Special requests and parking requirements

## 🛠️ Tools & Technologies

- **Python** – Data Analysis
- **NumPy** – Numerical Operations
- **Pandas** – Data Manipulation and Analysis
- **Matplotlib** – Data Visualization
- **Seaborn** – Statistical Data Visualization
- **Jupyter Notebook** – Development Environment

## 🔍 Analysis Performed

The project explores the following areas:

**1. Booking Analysis**
- Most preferred hotel type
- Booking cancellation percentage
- Yearly and monthly booking trends
- Most preferred meal type

**2. Customer Analysis**
- Country-wise guest distribution
- Repeated guest percentage
- Customer type and market segment analysis
- Special requests and guest preferences

**3. Hotel Performance**
- Most preferred and assigned room types
- Top booking agents
- Hotel revenue comparison
- Average Daily Rate (ADR) analysis
- Booking waiting time

**4. Business Insights**
- Distribution channel performance
- Guest stay duration
- Business recommendations
- Final project conclusions

## 📊 Project Approach

The analysis follows an Exploratory Data Analysis (EDA) approach using Python libraries to examine the dataset, identify patterns and present findings through visualizations.

## 📁 Project File

- `EDA Project (3).ipynb` – Jupyter Notebook containing the analysis, code, questions and visualizations.
